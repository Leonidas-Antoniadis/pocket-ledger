# Pocket Ledger – mobile app

Expo (React Native + TypeScript) app. See the [project README](../README.md) for features, how to run it with Expo Go,
how to build an APK with EAS, and the data model.

```powershell
npm install
npx expo start        # dev server, scan QR with Expo Go
npm run typecheck
npm run lint
npm test
```
